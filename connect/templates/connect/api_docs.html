    Matches scheduled in each weekly cycle, oldest first, as {"records": [{"date", "count", "participants"}, ...]}. A week with no matches is listed with a count of 0, so a line chart shows the gap. The line chart reads it with "format": {"property": "records"}.

    Try: {{ examples.summary.1 }}

Responses

Success: 200

The venue and match lists share one shape: count, the filters that were applied, and results. Each result carries a url to its page on the site, built from the model's get_absolute_url(). Every endpoint can be read from any other site (Access-Control-Allow-Origin: *), so a chart in the Vega-Lite editor can load it.

Bad parameter: 400

An invalid value is never ignored. The response names each bad parameter and how to fix it:

{"error": "Invalid query parameter.",
 "fields": {"min_seats": ["Use a whole number, e.g. min_seats=8."]}}

No such match: 404

/api/icebreakers/ answers with an error naming the id when no match has it.

Open Trivia DB failed: 502, 503, 504

When /api/icebreakers/ cannot get questions, the error says why: 504 if Open Trivia DB took longer than 5 seconds, 503 with Retry-After: 5 if it is busy (it takes one request every 5 seconds), and 502 for any other failure.
